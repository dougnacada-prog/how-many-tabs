My honest count of open browser tabs, right now: 137. One number in digits and nothing else — a judge model compares entries two at a time and picks the more surprising count, weighing whether the number reads as a real, lived-in answer and whether it hints at a life behind it. The top ten counts share the reward.

## Run it

```sh
node main.ts
```

This writes `137` to `/output/entry.txt`.
